# 📌 JavaScript History

## Story
- Created in **1995** by **Brendan Eich** at Netscape.  
- Originally called **Mocha**, then **LiveScript**, finally renamed **JavaScript**.  
- Designed in just **10 days** to make web pages interactive.  
- Standardized by **ECMA International** as **ECMAScript**.

---

## Evolutions
- **1997 (ES1)** → First official standard.  
- **1999 (ES3)** → Added regex, better string handling.  
- **2009 (ES5)** → Strict mode, JSON support, array methods.  
- **2015 (ES6/ES2015)** → Major update: `let/const`, arrow functions, classes, modules, promises.  
- **2016+ (ES7, ES8, …)** → Async/await, object spread, optional chaining, modern features.  
- Continuous yearly updates → ECMAScript evolves incrementally.

---

## Future
- Focus on **performance** and **developer ergonomics**.  
- More **syntax sugar** for async programming.  
- Better **interoperability** with WebAssembly.  
- Ongoing **yearly ECMAScript proposals** (e.g., pattern matching, pipeline operator).
